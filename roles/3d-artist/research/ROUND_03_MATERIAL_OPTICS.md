## Critique and adopted direction

The actual preceding 1440 FORM/OVERVIEW captures have many small bright reflections across the supplied curved surface. Together with the source's genuine openings and shadow spots, the finish reads like crumpled foil. A moving warm material band and fine horizontal contours also compete with the shape. The new direction is a broad satin-silver response under controlled area lights, with dark and bright regions that explain curvature. The source geometry, normals, holes and base arrangement are not smoothed or replaced to achieve this appearance.

The image also kept the object behind nearly every evidence panel. That weakens the distinction between geometric inspection and source photographs. FORM remains the complete assembly reference, SYSTEM shows separated layers, PATTERN deliberately cuts through a macro view, MAKE/VALIDATION give the photographs an interval without the model, and CREDITS brings back a complete quiet silhouette. Motion Designer retains the existing unequal holds and shared response clock; Cinema does not add a second time law.

## Primary research and choices

- [Three MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html) provides anisotropic metal response, with extra shading cost. Adopt its physical lighting rather than an unlit custom metal shader. The installed source confirms the anisotropy frame uses tangents or UV derivatives; the approved GLB contains only POSITION/NORMAL. Therefore an original projected source-local axis supplies the frame in view space. It is an authored brushing direction, not a measured rolling direction. Clearcoat is disabled.
- [Pinned physical-light shader](https://github.com/mrdoob/three.js/blob/9b4a2ac29c63ccb43fd51c5661f2f873ac2c39b8/src/renderers/shaders/ShaderChunk/lights_physical_pars_fragment.glsl.js) shows the rectangular LTC route uses isotropic material roughness. The broad area-light highlight is therefore described as satin shading; anisotropy affects supported directional/IBL routes. Lighting Designer independently verified this limitation and supplies real RectAreaLights, with reduced busy HDR contribution.
- [Tiffen Black Pro-Mist](https://tiffen.com/products/black-pro-mist-filter) describes contained highlight diffusion and softer contrast. Adopt the observable relationship between bright sources and their neighboring image, without claiming a calibrated filter density or exact optical simulation. The implementation spreads real scene-linear highlight radiance; it does not blur the HTML or add an arbitrary gray overlay.
- [Three UnrealBloomPass](https://github.com/mrdoob/three.js/blob/9b4a2ac29c63ccb43fd51c5661f2f873ac2c39b8/examples/jsm/postprocessing/UnrealBloomPass.js) supplies the primary reference for HDR bright extraction and separable blur at reduced resolutions. A full five-level bloom chain is unnecessary here. Adopt two original quarter-resolution, nine-tap gathers and retain the existing one display transform, alpha convention and DOM masks.

## Implemented interfaces

`createCinematicMaterial({bounds})` retains `update/inspect/dispose`. Its revised default finish uses silver-gray `#929ea3`, metalness 0.96, roughness 0.58, anisotropy 0.35 and no clearcoat. Fine source-local roughness/color strands are derivative-filtered away when unresolved. The former gold sweep/contours are removed. The existing progress diagnostic remains for compatibility; progress does not invent material movement. `update({finish:'legacy'})` provides an isotropic previous-base-BRDF comparison under the same new lighting, not a recreation of every old animated cue. Set `finish:'satin'` to reset. Values change without rebuilding the shader variant.

`sampleOpticalScore` adds `mistStrength`, `mistRadiusPx` and `mistThreshold`. The shared chapter strength ranges from 0.16 to 0.42, with a lower portrait multiplier. Radius is in CSS pixels; the starting linear luminance threshold is 0.65 with a soft extraction knee. FORM and evidence holds remain sharp. Overview DOF is reduced so it does not obscure the improved finish. The old scene-dip control remains available diagnostically but its authored value is zero; the camera now performs a continuous exit.

The compositor's graph is scene HDR/depth → optional highlight horizontal extraction → optional vertical spread → depth-aware image/scene-derived ASCII/masked diffusion → one output transform. Mist takes pre-DOF scene radiance. Its operation combines small direct attenuation with added neighboring highlight energy. It is a physically inspired screen-space approximation, not an energy-calibrated lens model. Both diffusion and glyph contributions respect the padded protected rectangles. Empty corners stay transparent unless a real bright source falls within the finite kernel; such halos deliberately expand alpha coverage. Optical intensity never changes the source photograph pixels.

Full rendering uses four passes when diffusion is enabled, two otherwise. Two quarter-resolution RGBA16F targets add approximately `ceil(width*dpr/4) × ceil(height*dpr/4) × 16` bytes, excluding driver overhead, and are retained until disposal. They add no source geometry pass. Light/reduced set `mistStrength=0` along with DOF/ASCII. All targets/materials are explicitly disposed. No autonomous frame or CPU readback was added.

`sampleCinematicPose(...,{sharedStage:true})` adds `sourcePresence` and `framingIntent`. Only MAKE through VALIDATION has presence zero. The camera carries the source fully left before that absence and returns from the right afterward. The parent sets the source GLTF group's visibility only at exact zero; the exhibition scene remains visible. There is no translucent-metal fade or whole-Canvas fade. Reduced motion uses a fixed complete-source CREDITS pose with presence one. Paused/still policy belongs to the parent controller, which supplies the same reduced sharp composition.

The chapter definitions change only the shared case path; the previous role comparison desk's default sampling remains separate. One parent camera writer still sets position, look-at, film gauge, focal length and view offset. The Motion Designer owns response/holds and DOM feedback; Lighting/Scene Designer owns lamps and stage. No competing model-visibility score was introduced.
