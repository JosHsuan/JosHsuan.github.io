The review servers are opt-in local processes, not hosted deployments. Each role README describes its pinned tools, build commands, licences and verification limits. Existing test reports are dated evidence; a new checkout does not imply a fresh successful test run.

The [round-02 team](experience-director/research/ROUND_02_TEAM.md) and [layer contract](experience-director/research/ROUND_02_LAYER_CONTRACT.md) establish responsibilities for the next local case revision. Cinema extends into optical attention and editing; the 3D Artist owns depth-driven compositing and scene-derived ASCII. This checkpoint records role setup and research. The new camera, lighting, base geometry, animation and layer effects still require implementation and rendered acceptance in the case.

Version control retains source code, original specimens, licensed public reference assets, role skills/configuration templates, documentation and sanitized verification summaries. It excludes dependencies, generated builds, runtime homes, credentials, private source audits, thesis narrative/media/model handoffs and geometry-derived framing support. Do not force-add ignored local data when preparing a commit.

The thesis case is intentionally not self-contained in a fresh clone. An authorized local handoff must supply its ignored content snapshot, assets and private framing module.
