## Interaction contract

Natural document layout remains authoritative for anchors and browser semantics. Enhanced chapter inners are relative rather than sticky; the moving reading plane is clipped by its natural-height wrapper so transforms do not add scroll range. Heading, prose, image and method channels use the visible reading coordinate. Local pointer/focus feedback has bounded perspective and shares the existing tick. Reduced/Pause restore identity transforms; explicit model controls apply immediately.

Native touch pans through the model slot. Mouse drag and arrow keys deliberately change bounded model views. Compact View/Layers/Light controls keep the source nearby. Choices persist while scrolling out and back. No modal, backdrop interception, body scroll lock or second animation loop remains. The same source geometry and approved documentary images remain available without 3D.

The shared response must seek for keyboard focus, hashes, browser history and visibility resume, using natural coordinates. A seek within a hold bypasses that one shoulder until the user leaves it, preventing the next small wheel movement from pulling text backward. The mobile clear-slot gate reaches zero continuously before its minimum valid projection height.
