# Team and decision rights

The new role is **Interactive Experience Director**. The current gap is composition and coordination across already-capable specialists, so another shader artist, generic developer or separate project manager would duplicate responsibility.

| Role | Owns | Handoff to the director |
| --- | --- | --- |
| Interactive Experience Director | Narrative/scene relationship, chapter/layer contract, cross-role decisions and rendered acceptance | Shared contract and actionable visual review |
| UIUX Designer | Semantic content, source evidence presentation, responsive layout, HTML layer/fallback and pointer icon feedback | Stable chapter hooks, evidence crops, readable HTML |
| 3D Artist | Material/light/shader techniques and their visual/technical limits | Bounded reusable shading, source/license records, cost limits |
| Animation Cinematographer | Real-geometry framing, coherent transition poses, decorative pointer composition | Pure camera sampling with one final writer and deterministic tests |
| Geometry Engineer | Real CAD inspection/conversion, stable geometry, source/derivative provenance | Normalized assembly and trustworthy model/asset records |
| Integrator (parent implementation responsibility) | Canvas lifecycle, combined runtime, material staging, build and end-to-end verification | Working local case artifact and current evidence |

The integration responsibility is necessary, but is performed by the parent implementation agent within this task; it does not need another installed tool bundle. No new geometry, fabrication, research or rights claims are created by the director. Source uncertainty remains with the evidence instead of being resolved by visual design.

On 2026-10-08 the director, UIUX and cinematographer agreed seven semantic chapters, left/right composition rhythm, native measured DOM anchors, a single camera writer and decorative pointer motion. The director's initial six-chapter idea was refined to retain a separate pattern-detail beat because UIUX supplied actual specimen evidence; the maintained contract contains the final decision.
