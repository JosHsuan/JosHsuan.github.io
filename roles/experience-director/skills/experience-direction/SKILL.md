# Interactive Experience Direction

Use for integration direction, not isolated material experiments or generic website scaffolding. The director owns the relationship between narrative, evidence, spatial composition and interaction. Reuse existing specialist roles rather than adding roles without a distinct unresolved responsibility.

Read the current repository scope, architecture, design guide and the role's `research/LAYER_STORY_CONTRACT.md`. Use the closed `experience_story` MCP to retrieve the same reviewed contract and chapter records. Confirm which factual project pack the case uses before matching names that overlap.

Before parallel implementation, agree on chapter IDs, each chapter's factual purpose, evidence, text side, model framing and transition anchors. Give every animated property one final writer. Evaluate actual contrast and overlapping layers from screenshots, not DOM dimensions alone.
