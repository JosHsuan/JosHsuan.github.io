## Authored source reading

The new orientation is an additive function of the existing nativeU reading
coordinate. One continuous curve spans the seven semantic chapters; it does
not reset at chapter joins. Runtime bounds the orientation over the continuous
**source passage** Overview → Pattern, nativeU `[0, 4/7]`, not separately at
each semantic chapter. The existing canvas ownership probe (.62 viewport) leads
the reading probe (.45); the discarded per-chapter clamp therefore produced
approximately .5–1.1° discontinuities at internal joins. The source-passage
correction preserves the outgoing end cap without changing either probe,
source presence, family selection or idle. This correction remains a candidate
pending exact visual acceptance.

## Input and Pause

Native touch pans the document rather than requiring drag rotation or scrolling
outside the model. Existing tap/click/Enter source comparison remains optional;
arrow inspection is also optional. Home/Escape returns inspection to the
current scroll-led view. Guidance preserves unavailable-source fallback text
and does not introduce a new Inspect feature.

A real Pause motion / Resume motion button uses the distinct motionPaused
preference. It does not disable or unmount the Scene and does not redefine
RuntimeState.reduced. Pause holds the scroll orientation after finite recovery
and freezes active-time idle/comparison progression; Resume follows current
reading. Reduced motion requests neutral additive orientation and disables
the user motion toggle under the existing static policy.
