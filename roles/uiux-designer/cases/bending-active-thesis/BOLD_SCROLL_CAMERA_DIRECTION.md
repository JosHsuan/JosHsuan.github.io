## Composition and physical safety

Every generic/XR orbit targets the verified source-bounds centre: normalized
`[.5,.5,.5]`. Fit zoom stays `1.00–1.18`: the close views use the full available
source aperture; the establishing/ending views open breathing room. The fitter's
minimum distance is `1.1 * enclosingRadius` before this multiplier, so the eye
stays outside every possible source solid within that sphere. All intermediate
poses, not just endpoints, are fitted after yaw/pitch/FOV are composed.

Generic desktop aperture remains centre `[.735,.53]`, size `[.51,.78]`; mobile
uses `[.5,.42]`, size `[.94,.45]`. The canvas is still full viewport; view offset
preserves negative space for native text rather than translating text or cropping
the source. XR uses its existing source/phone-specific reading apertures. Bending
retains its verified family-support fitting and actual native model-information
layout. Mobile receives the same authored arc in its own fitted aperture, not an
automatic motionless substitution. No wide-angle roll, whip pan, tunnel flythrough
or screen-text perspective distortion is added.

The rejected Dot close crop is not repeated: **all generic source bounds remain
visible at every scroll sample**. Larger yaw/elevation and dolly/lens contrast
provide the new boldness without sacrificing orientation. No factual detail is
claimed merely because a camera angle suggests it; retained pixels decide that.
