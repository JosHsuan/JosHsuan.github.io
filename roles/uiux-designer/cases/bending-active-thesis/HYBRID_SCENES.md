## Story and source roles

Special Assemblies begins with its original complete `hero.webp` physical view beside the original summary and role/credit information. Context and System retain the original assembly, inspection, scroll camera, source panels, and complete technical evidence. Making retains the original 7.56-second nonloop **simulation**, not physical-execution footage. Results brings `front-prototype.webp` and `assembly-detail.webp` into native flow as complete 3120 × 2080 images, with the original prose and adjacent glass information. The latter retains its existing evidence action. No planning guide, new controls, depth effect, invented ordering, or generated assets are added.

The reusable grammar is source-specific: native still / leased model / authored video. It is not a universal replacement of true model or film scenes with photographs.

## Ownership

Explicit native chapters are Overview, Results, and Credits. Their original images are not registered as fixed backdrop records. A native-only backdrop transaction must close the outgoing source's finite exit and settle absent without fabricated source readiness or a blank image asset. The existing model is retained, and reverse native reading may return to its same owner. The native movie owns its own time; leaving it must stop transport/callback demand. Latest-wins, Pause, hidden, Reduced, Save Data, error, and disposal policies remain in the existing owner.

Native image load/error listeners use the existing driver scope and add no fetch, decode, independent frame clock, or renderer. Cas output and other project source paths must remain unchanged.
