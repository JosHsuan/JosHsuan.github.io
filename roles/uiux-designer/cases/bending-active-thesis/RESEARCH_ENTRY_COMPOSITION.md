# Original-source entry composition

## Baseline and purpose

The research-led Home exemplar is published at `2477c4427e8c02b3a61853c52e7c2cc4137806e3`, validated by push run `40149950180` (525 public-browser cases and 24 framework cases) and deployed by Pages run `40152189380`. Live verification matched all 265 exported files, including the 137 original assets, and confirmed the genuine missing-route 404/noindex response.

Its native entry is deliberately not a shared GPU scene or seamless camera morph. Actual video showed an avoidable additional boundary: outgoing used the desktop poster even on mobile, while arrival selected the original mobile poster; outgoing also applied a separate 0.96 scale. The destination's default server-rendered loader then changed layout when the handoff hint was adopted. These are presentation differences, not a reason to delay native navigation or transfer scene readiness.

## Bounded candidate

- One pure `ResearchEntryComposition` provides the existing responsive poster selection, complete-image containment, background and information tracks.
- Bending's loader uses that composition in its server-rendered default, including direct entry. A valid Home research departure uses the same presentation. Adopting a ticket no longer changes the destination's frame geometry.
- Both original poster files remain byte-identical. No framebuffer capture, generated image, geometry/material/camera change or new animation clock is introduced.
- Desktop places readable information left of the original specimen. Narrow windows (up to the original 780px picture breakpoint) use a minimum 44-rem frame with readable information above the specimen. Short landscape windows use two native-scroll rows rather than overlapping information and source or shrinking text.
- The original truthful page/study titles, loading status and Return destinations remain distinct. The two information tracks reserve matching space; matching composition does not require pretending that the documents or preparation states are identical.
- Native links, eligibility filters, cancellation, inert restoration, failure deadlines, independent destination preparation, disposal, Back/Forward and static policies retain their existing owners.

## Whole-site grammar, not a universal effect

The reusable language is **identity → source evidence → destination-owned reading**, with a consistent readable information track and a reviewed image track. A later project adaptation must use that project's original source, contribution and destination semantics. It must not inherit the Bending model or claim physical motion from a decorative transition. Different source aspect ratios and narrative purposes may need different reviewed frames; the first exemplar does not authorize indiscriminate full-site animation.

This candidate implements only the Bending exemplar. Ordinary-page loaders and other case defaults are not restyled. There is no generic source registry, external service, new preload or timing policy.

## Acceptance boundaries

1. On genuine native navigation, preserve the existing observer/video method: no page query or screenshot while the destination document is intentionally held. Compare actual responsive `currentSrc`, natural dimensions and fitted image-content bounds between outgoing and committed arrival.
2. Use conservative, manually reviewed original-image subject envelopes only for QA clearance. They are not runtime crops, model segmentation or a pixel-equivalence claim. Preserve complete shell/base visibility and readable status/Return controls.
3. Verify direct server-rendered loading before hydration, common portrait and short-landscape layouts, native loader scrolling where needed, forced colors, Reduced Motion and no-JavaScript fail-open behavior.
4. Retain the existing navigation/readiness tests and exact-artifact full publication gate. Do not relax timeouts or postpone navigation to obtain prettier frames.

The live-model-to-raster change in pose, lighting and negative space remains. Full-image containment can reduce the previously small poster subject, but cannot promise the same scale as the live convex-fit hero at every viewport. Reduced-resolution video supports observed continuity only; original PNGs and actual geometry receipts support readability and framing. Independent source review and 131 CI contracts pass. Actual browser/render acceptance of this new candidate is pending; direct SSR coverage includes 320px, the 780/781px source boundary, 900px square/portrait and short landscape. No visual or publication result is implied by source checks.
