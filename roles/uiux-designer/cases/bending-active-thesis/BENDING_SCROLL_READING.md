# Bending-Active — native scroll reading

## Owner revision, 26 October 2026

The current owner instructions remove unnecessary buttons, original-image opening
UI and click-gated reading inside project pages. Page-to-page links remain.
The subsequent instruction removes visible accessibility and motion-pause tools
and automatic no-motion switching. Semantic headings, image alternatives and
native keyboard scrolling remain ordinary document structure, not extra controls.

This revision is scoped to the existing selected application. It does not populate
the reusable empty framework or change any public source-image, geometry, material,
lighting or provenance bytes. The separately authored bold camera path is described
in `BOLD_SCROLL_CAMERA_DIRECTION.md`.

## Runtime ownership

The existing Director remains the only animation scheduler and publishes native
reading progress. `resolveSourceSelection` accepts that native progress on the live
route; its chapter-local fraction selects each original source in order. Waiting
at one position cannot change the selected representation. Reverse scrolling
reverses the same sequence. Existing independent subtle idle lighting/camera cues
remain; this is not a claim of zero motion when the pointer and scroll stop.

Source support fitting, the final scene writer, single retained Canvas, original
GLB data and renderer pressure/lifecycle safeguards remain. ModelInspector no
longer registers pointer or keyboard comparison/inspection features. In particular,
removing its button role is accompanied by removing the document-level
`model.pointer` connection, so a raycast cannot quietly restore click selection.

The route does not query or observe `prefers-reduced-motion`, expose an Enable or
Pause control, or disable current motion because of Save-Data. Actual failed WebGL
and a previously failed/interrupted resource lease retain honest native reading
fallback. Hidden, pagehide, freeze and disposal still stop unnecessary work.

Miura/workflow descriptions are native HTML before diagram JSON hydration. Their
static values are transcribed from the pinned public diagram records and checked
against those records by the focused source test. No source diagram needs a
button, hover or timed caption change to explain its content.
