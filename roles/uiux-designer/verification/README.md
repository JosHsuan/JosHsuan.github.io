## Findings corrected during validation

- A current Lucide filename is code-xml rather than the older code-2 name; pinned acquisition uses the existing upstream file.
- Next's bundled standalone production minimizer path is unavailable. The role build retains production mode without minification, keeping the dependency set unchanged.
- This Windows host rejects the regular Chromium executable launch from MCP with spawn UNKNOWN. The existing stable Playwright headless-shell executable was derived from the installed revision and successfully used by the role MCP.
- Native dialog close dispatch is asynchronous; verification waits for actual iframe disposal. Saved-state changes now preserve the active specimen rather than rebuilding its iframe.
- WebKit needed an explicit skip-link tabindex; keyboard transfer is verified. Specimen height follows its content to avoid nested review scrollbars.
- During the new key test, WebKit blurred a previously keyboard-focused button on mouse-down. The blur handler incorrectly released an active pointer press. It now distinguishes pointer capture from keyboard blur; the outer button remains a stable hit area while its inner key rig rotates. Keyboard, mouse cancellation and touch checks then passed.
- Demand-loop assertions now observe a stable frame counter over a sampling interval after queued invalidations settle. An initial idle flag alone was insufficient evidence that the last requested frame had already rendered.
- In the feature page, a search input consumed Escape before native dialog dismissal. Its explicit Escape handler now closes the actions panel. WebKit does not necessarily focus a clicked opener; explicit opener references now restore focus after image/actions/3D dialogs close.
- Screenshot review exposed stale navigation emphasis at the page opening and a comparison tray over unrelated workbench controls. Location updates now reflect the actual reading position, clear at the opening, and show the tray only while browsing/reading. Native anchor offsets were corrected so sticky navigation and section positioning agree.
- Applied feedback review corrected default pressed-button backgrounds that hid icon depth, heading/linework framing near the stage boundary, and ASCII text clipping at higher density/narrow widths. The original WebKit command-focus regression now awaits the asynchronous dialog close/focus restoration instead of inspecting it in the same event turn; the actual focused opener is still asserted.
