## Plan and critique before implementation

Use graphite #0b0d10, raised #14181d, drafting #23313c, paper #f2f0ea, muted #a7adb5 and interaction #ff7a45. Existing local font families and assets remain the specimens. Keep controls/captions aligned below a single large stage; labels and targets stay flat while inner objects own depth. Each specimen gains Baseline / Spatial feedback, and direct-state reduced motion.

The rejected approach was a universal tilt on the specimen frame. That would not demonstrate how spatial meaning changes with the material. Instead, implement distinct object-level actions:

| Existing materials | Applied behavior | Property boundary |
|---|---|---|
| Five font families | Fan short heading words; lift an inspected heading; keep paragraph still | Word spans only; original editable text/weight/size remain |
| Three icon families | Lift the selected glyph, press/release and return; keep original SVG download | Inner glyph rig; fixed labeled button |
| Identity glyphs and palette | Open thematic mark plates and separate actual color swatches | Decorative object only; captions/contrast evidence still |
| Focus rail / command interface | Selected detent and a real outline/filled object with separated faces | Native input owns state; nested visual owns depth |
| Aperture / trace / reflow | Hinged reveal, layered construction lines, individually inspectable nested part faces | Existing playback/GSAP owns original properties; depth has a separate owner |
| Theatre section | Actual authored separation plus selectable extruded section faces | Adapter owns outer groups; local inspection owns inner groups |
| Wave field / hatch | Pick a field band and locally lift its real vertices; shader marks that band | One response writes geometry/uniforms; one stepped-camera owner |
| ASCII | Decompose actual generated height samples into low/middle/high planes | Deterministic text projections; readable description unchanged |

Spatial is a new proposal mode, not an inferred owner approval. Baseline is the comparison control. Existing Saved preferences remain authoritative and can include these same stable material IDs. Do not copy reference assets or introduce optional libraries. No new authored timeline is needed: retain the actual versioned Theatre score and map direct interaction independently.

## Research basis

- [Lucide accessibility](https://lucide.dev/how-to/accessibility), checked 7 October 2026: semantic labeled controls, consistent meanings and sufficient hit regions. Applied inference: animate the inner glyph rather than moving its button.
- [W3C interaction animation](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html), checked 7 October 2026: nonessential interaction animation can be disabled. Applied inference: retain selection and expose direct end states when motion is reduced.
- [MDN transform-style](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/transform-style), checked 7 October 2026: 3D descendants and flattening properties constrain composition. Applied inference: separate the stable clipping viewport from the preserving inner rig.
- [R3F demand rendering](https://r3f.docs.pmnd.rs/advanced/scaling-performance), checked 7 October 2026: explicit invalidation supports idle scenes; mutations need a requested render. Applied inference: the response kernel updates buffers/uniforms and invalidates while moving, then stops.

These sources support implementation constraints, not claims that the proposed aesthetic is prescribed by them. Exact installed packages remain authoritative; no upgrade follows from newer documentation.
