# Motion Designer

Read the role's [contract](../../research/RESPONSE_CONTRACT.md) when defining channels and [sources](../../research/SOURCES.md) when selecting algorithms or preparation tools.

Keep native scroll, focus, selection and reading position immediate. Add time response to a separate visual playhead and derive stage, lens, light, material and decorative channels from one bounded response state. A dwell is a designed interval with an explanatory composition; it is not an input trap or an arbitrary timeout.

For each chapter identify entry, hold and exit, what remains legible, which layer reacts to motion energy, and what becomes still. Preserve velocity through target changes; test acceleration, deceleration, reversal, long-jump catch-up and equivalent wall-clock behavior at different refresh rates. Stop requests once position and velocity settle. Reduced motion resolves to a useful static composition, with semantic information still complete.

Do not install Lenis merely to make a wheel feel heavier or stack GSAP scrub smoothing on a second spring. The selected response must have one owner. CSS handles simple hover/focus; shared layer feedback receives a prepared influence contract. Use the role's read-only score MCP to inspect approved chapter timing, then verify actual rendered behavior through the role browser profile.
