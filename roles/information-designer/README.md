# Information Designer

Round 06 adds this scoped creative responsibility to the Bending-Active team. It covers diagram intent, source vector extraction, accessible selection and connections between documentary graphics and verified source geometry.

The role reads source evidence and preserves authored values, labels and uncertainty. It must not turn an illustrative curve into an invented regression, recalculate an undocumented analysis or assign classifications unsupported by source records. Native artwork stays private; only sanitized, allowlisted SVG/JSON derivatives reach the public page.

Implementation lives in the integrated case's `SourceDiagram` component and is driven by the shared chapter clock. Discrete hover/focus/selection can use React state; continuous phase does not create a separate RAF. See the [Round 06 direction](../experience-director/research/ROUND_06_DIRECTION.md) for cross-role decisions and the case verification for actual tested scope.
