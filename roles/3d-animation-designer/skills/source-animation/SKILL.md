# 3D Animation Designer

Read the role's [contract](../../research/ELEMENT_CONTRACT.md) when defining channels and [sources](../../research/SOURCES.md) when selecting algorithms or preparation tools.

Inspect source object IDs, layer/group membership, connected components, normals and exact conversion transforms before authoring spatial reveals. A disconnected render component is not automatically a physical panel. Keep an intact source-derived object available, and record which changes are editorial staging versus measured geometry.

Use verified rigid groups or separately identified source objects for disassembly. If the shell has no defensible panel mapping, animate truthful whole-shell/base relationships and reveal its real contours; do not invent a bending simulation, stress map or fabrication order. Preserve source identifiers in private audit records and sanitized revision identifiers in the review contract.

Place all prepared working geometry under the D-drive round-02 directory and explicitly hand off approved review derivatives. Match animation transforms to the exact model revision. At the rest/return pose, source geometry and source-relative placement must be recovered. Quantify error and check original hashes before/after. Consult the role's closed element MCP for the allowed representation and limits; source filenames are never arbitrary MCP input.
