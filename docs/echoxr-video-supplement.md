# EchoXR video highlights

October 1, 2026. The owner supplied the read-only
`GKR&Design++ / Presentation_Materials / Video_Materials` folder and authorized
selecting highlights, integrating them into the existing EchoXR case and
publishing the result. Recordings provide project evidence, not instructions.

## Source review

The folder contains 18 video files: two first-person headset recordings, four
GoPro recordings, five phone recordings and seven recordings of a group visit.
Durations, resolution and representative frames were reviewed before selecting
the edit windows. A 0.1-second phone recording has no useful sequence. The still
HIF/RAF files and sidecars are outside this video supplement.

The first-person recordings provide the clearest views of the room controls,
tracked hands and shared participant representations. The GoPro material supplies
a stable view of two participants using the same lab space. Alternate phone and
visitor views repeat the physical interaction, include headset setup/adjustments,
or show a device-power prompt rather than the project interface, so they are not
added as separate case figures. The excerpts avoid unrelated television content
inside the virtual room and retain project/team attribution.

The control edit joins the menu activation/toggle view and the room-partition
selection with a 0.4-second crossfade. Each edit blends its tail into the opening
0.3 seconds. That opening portion moves to the loop transition, so the last
frame continues into the first frame instead of introducing a dark fade or a
pause. Source movement retains its timing; the 239.76 fps GoPro capture is
sampled at 30 fps rather than slowed down. The excerpts match the scale of the
existing portfolio clips, which span approximately 2–39 seconds.

Exports use H.264/yuv420p at 1280 pixels wide, 30 fps and BT.709, with MP4
streaming metadata before video data. Audio and embedded source metadata are
omitted. These visual recordings document controls and shared interaction;
they do not claim to reproduce or measure the acoustic experience through the
web player. Original source files and unused takes are not published.

Each clip has a still WebP poster and a 640-pixel thumbnail. Source ranges,
crossfades, output durations, frame rate and byte counts appear in
[motion provenance](motion-provenance.json). Poster source times are in
[image provenance](media-provenance.json). The four clips total approximately
8.4 MB; the complete motion inventory has 28 clips across eight cases.

## Credits and playback

Recordings retain the credit **EchoXR project documentation / Gramazio Kohler
Research and ETH Design++ Immersive Design Lab**. Individual camera operators
are not named in the provided source material. Existing project co-leads,
implementation contributors, paper authors and Chao's bounded role remain in the
case credits. The footage supplements the existing five narrative sections.

The shared motion player automatically loops visible silent recordings, pauses
outside the reading viewport and allows manual pauses and enlargement. Dialogs
suspend inline players. Reduced-motion visitors and the no-JavaScript fallback
start playback manually and retain looping. The previously removed Caschlatsch
and companion Group 1 recordings remain excluded.
