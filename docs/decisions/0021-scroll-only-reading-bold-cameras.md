# 0021 — Scroll-only reading and authored camera journeys

Status: accepted for the selected public application, 26 October 2026.

The owner explicitly requests that each project be readable with scrolling alone:
remove original-image opening links, click-dependent disclosures, model inspection
and unnecessary in-page buttons; retain links that change pages. The subsequent
direction also removes visible Skip/Enable/Pause controls and automatic motion
replacement driven by OS motion or data-saving preferences. Native headings,
image alternatives, ordinary keyboard scrolling and honest resource-failure
fallbacks remain; these do not add a reading interaction.

Substantive source descriptions, method notes, research figures and credits move
into native document flow. Existing source assets and scientific claims stay
unchanged. Bending's source variants follow native chapter progress rather than
an autonomous cycle. Camera journeys become bolder, case-specific exterior arcs
and cranes; source geometry, bounds-based full fitting and sole camera ownership
remain. Main camera progress is authored by scrolling, separate from the retained
subtle handheld idle treatment. Phone recordings keep readable frontal framing.

This supersedes earlier requirements to retain original-view UI, model-gesture
inspection, visible motion controls and automatic static presentation. It does
not authorize new paid services, fabricated measured geometry, private-source
publication, host security changes or weakening the exact-artifact release gate.

Implementation is first qualified on an isolated, nonpublishable preflight ref.
A successful build or numerical source-framing test is not visual acceptance.
Full CI and independent rendered desktop/mobile motion review remain required
before public deployment.
