# 0021 — Continuous motion, spatial cards and project showcase

Date: 3 November 2026 (Europe/Berlin). Status: authorized implementation;
acceptance and publication remain pending for this revision.

The owner authorizes a systematic review, implementation, commit, push and
GitHub Pages publication of the selected public application, using free tools
and services. The verified starting point is `a46a65aebc5c69c805d6e9740d5366ab451d8e63`
on local main, GitHub main and public release.json. Earlier pending-publication
notes are historical, not the current release state.

The new scope supersedes earlier presentation restrictions where necessary:
remove motion pause controls and preference/performance-triggered static modes;
unify reading-card motion; redesign all project materials, lighting, camera and
transitions; add the supplied Mode/s machine and Caschlatsch models; improve XR
phone-media clarity; remove image enlargement/open-image interactions; adopt
the owner's preferred 80%-zoom visual density through responsive design tokens;
and replace Home's Bending-only research story with an introduction, a rotating
multi-project product-film backdrop, a scroll-driven project-card discovery
sequence and Contact. The separate Project route retains the complete index.

The owner's later amendment requires compact square cards with event-driven
selection on card instances, Apple/Lusion-informed project design rules, and
photographic rather than uniform clay materials. Home camera direction is
source-scale-specific: architectural models may be shown in partial human-scale
views instead of forced full-model fits. The cinematography and scene roles
jointly review these shots. See the
[design direction](../../roles/uiux-designer/cases/bending-active-thesis/PORTFOLIO_DESIGN_DIRECTION.md).

The two supplied diagrams and subsequent clarification define a shared curved
field of view, analogous to running inside a wheel. Native scroll velocity and
acceleration drive depth, curvature, peripheral stretching and liquid recovery.
Independent identical card tilts do not satisfy this direction. Stopping scroll
settles the card response; scene idle motion continues. Focused controls and
text selection retain usable native hit areas.

One existing scheduler and final writer remain per established presentation
owner. Hidden/frozen documents, actual GPU/context failure and permanent exit
retain lifecycle protection; they are not visible-page motion modes. Original
source bytes/geometry, evidence and credits remain protected. New public model
and media derivatives require explicit provenance and byte validation. The
reusable framework remains empty and private paths never become runtime inputs.

The [implementation contract](../../roles/uiux-designer/cases/bending-active-thesis/CONTINUOUS_MOTION_INTEGRATION.md)
defines acceptance. Exact-version tools, built-artifact browser checks and the
same-artifact CI/publication gate remain mandatory. No additional publication
approval is required within this scope.
