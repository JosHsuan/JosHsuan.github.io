Date: 5 November 2026. Status: authorized implementation; qualification pending.

The owner requests a major redesign of **all motion** in the selected public
website, using the Glass Feed, Glass Carousel and Glass Stream examples at
[Align Canvas](https://aligncanvas.com/create). Implementation, commit, push and
GitHub Pages deployment are authorized. Paid features, paid services and trials
that can incur charges are forbidden.

surface passages and foreground entrance recipes within the selected application.

extended to the new bounded reading/card edge treatment. The central reading
region, focused controls, native content and documentary source identity remain
clear. This is an independently authored interpretation, not copied template code.

Always-motion direction, compact square discovery cards, card-instance selection
events, scale-aware cameras, original assets/geometry, existing scheduler/final
writer ownership, the empty reusable framework, exact toolchain and same-artifact
CI/publication gate remain. Native videos retain their own playback time.
